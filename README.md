# ALIEF CLEANPRO - update otomatis

File update ALIEF CLEANPRO (PT. Alief Energy Utama). Program membaca `alief_cleanpro_update.json`,
mengunduh paket `app-<versi>.zip`, lalu memeriksa ukuran, SHA-256 dan tanda tangan digital RSA
sebelum mengganti file .exe portable. Paket tanpa tanda tangan yang sah ditolak.
